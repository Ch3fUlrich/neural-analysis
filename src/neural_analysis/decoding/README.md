# Decoding

This module provides specific functions and classes for neural decoding tasks.

## Purpose

Decoding is the process of predicting or estimating underlying states, variables, or behaviors (such as position in space) given an observed neural population activity.

## What can be analyzed

- **Neural Decoders**: Includes methods such as K-Nearest Neighbors (K-NN) decoding and Population Vector (PV) decoding.
- **Evaluation**: Compare decoding performance using metrics like mean squared error across different models.
- **Cross-Validation**: Perform robust model evaluation across training and testing splits of the neural data.
- **High-D vs Low-D**: Compare the efficacy of decoding from raw high-dimensional neural representations versus lower-dimensional embeddings.
