# Topology

This module contains methods for topological data analysis, with a primary focus on the Structure Index.

## Purpose

Topological methods assess the global shape and "connectedness" of data independent of specific coordinate embeddings, revealing robust invariant features.

## What can be analyzed

- **Structure Index**: Compute the structure index, which quantifies the degree of 1D (ring-like) or 2D (sheet-like) topological structure within a neural population based on pairwise distance relationships.
- **Parameter Sweeps**: Run large-scale parameter sweeps to see how the structure index changes over different spatial or activity configurations.
- **Topological Visualization**: Use specific topological plotting functions to map distance graphs and similarity patterns.
