# Plotting

This module is a comprehensive, unified visualization suite for the project.

## Purpose

To provide a consistent and highly configurable interface for rendering 1D, 2D, 3D, and statistical plots. It supports both static publication-quality outputs (Matplotlib) and interactive explorative outputs (Plotly) via the `PlotGrid` dispatch system.

## What can be analyzed (Visually)

- **1D/2D/3D Data**: Plot simple line graphs, complex 3D trajectories, grouped scatter plots, and embeddings.
- **Statistical Plots**: Visualize data distributions using box plots, violin plots, and bar charts.
- **Heatmaps**: Represent connectivity matrices, similarity matrices, or parameter sweeps.
- **Custom Overlays**: Add horizontal/vertical threshold lines, error bars, and specific text annotations for analytical context.
