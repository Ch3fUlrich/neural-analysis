# Learning

This module contains algorithms for supervised classification and unsupervised clustering of neural data.

## Purpose

To apply machine learning techniques to characterize or partition neural representations.

## What can be analyzed

- **Classification**: Train supervised models (e.g., Random Forests, SVMs) to classify neural responses based on distinct stimuli or behavioral states. Evaluate performance and compare models.
- **Clustering**: Discover hidden categories or states within neural activity using unsupervised methods like K-Means or DBSCAN.
- **Decoding (Integrated)**: Works closely with the `decoding` module to predict continuous variables from population activity.
